# Pulang 收尾审查

审查日期：2026-11-19。范围：当前静态网站、45 个公开地点、17 种袋子物品、两组分类练习及资料维护流程。本文件记录当前版本的结论，不把测试通过等同于现实站点已经营业或接收物品。

- [x] 移除重复浮动袋子入口，保留顶部 My bag；数量显示在同一入口，关闭后键盘焦点返回入口。
- [x] 精简重复计数：正常显示地点数量，袋子范围显示 bag matches，不再重复显示 points / mapped。

- [x] 取消用户操作前自动选中第一个地点，避免把资料顺序误当推荐结果。
- [x] 逐条校验公开记录：单条记录失效只撤下该条；全部失效时提供官方目录，不使用历史资料补位。发布前检查仍严格拒绝任何缺项。
- [x] 校验物品清单的日期、唯一标识、材料、来源和处理路线；加载失败提供重试，损坏缓存不会使界面崩溃。

- [x] 检查键盘 Escape、袋子刷新恢复、搜索退出隐藏筛选、无匹配、单条无效、全部过期、地图库失败、清单请求失败和重试。

## 需要保留的边界

- [ ] 电话或实地确认公众访问、精确投放位置、当前营业和具体物品接收；公开页核对不能完成这项工作。
- [ ] 扩大目录覆盖并处理 79 条档案记录缺项或冲突；当前 45 点不代表槟城所有回收地点。
- [ ] 在 2026-12-15 前执行下一次人工资料复查；自动检查只提示变化，不会自动批准资料。
- [ ] 确定长期维护负责人和处理来源变更的时限。已有 PGC 官方建议渠道，但没有 Pulang 自己的后台或自动纠错闭环。
- [ ] 真实用户试用，验证找点速度、理解接收限制和实际投放成功率；目前不能声称已经产生环保成效。

## 后续增强，不作为本轮缺陷修复

两组固定练习的教育深度有限，尚未与用户自己的整袋清单直接连通。中文和马来语界面尚未实现。没有道路用时、多站行程优化、实时容量或实时营业功能；现有距离是到地图中心或定位点的直线距离，外部导航交给 Google Maps。需要先证明这些增强能解决真实使用障碍，再决定优先级。

## 评审判断

当前优点是本地问题明确、界面克制、资料可追溯，地图与袋子已经能联动。之前最不足的是不断新增控件，却没有同时清理状态之间的冲突，且曾以前三名硬限制掩盖真实候选范围。本轮收尾优先恢复一致的操作逻辑和故障恢复能力，不继续堆叠入口。

本轮没有把“按公开资料列出”升级为“独立验证”，也没有把项目包装为完整覆盖、持续实时维护的服务。GitHub 提交与线上部署是不同状态，部署结果应以实际页面及发布检查为准。
